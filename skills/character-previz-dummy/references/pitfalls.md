## 파일·운영
- 산출물을 `input/` 에 쓰지 말 것(사용자 지적). `out/<TAG>/` 고정.
- 폴더를 탐색기로 열지 말 것 — 경로 한 줄 + 용도 표.
- 삭제는 휴지통(`SendToRecycleBin`)만, 목록을 보여주고 확인 후. 영구 삭제 금지.
- scratchpad 스크립트는 세션 종료 시 사라짐 → 재사용할 코드는 `image-to-3D/pipeline/` 에.
- 정리 전 리깅 blend `pack_all` — 작업 폴더 텍스처가 사라져도 열리게. VAE6 는 원래 없던 `Unpack` 경로 7개가 남음(정상).
- 콘솔 한글 깨짐은 Git Bash 코드페이지 문제(파일은 정상). `.env` 는 Drive 하드링크라 에디터 도구가 거부 → 경로로 직접.
